# AGWI Webapp Projekt (2. Semester)

Dieses Projekt entstand im Modul **AGWI (Angewandte Grundlagen der Wirtschaftsinformatik)**.  
Ziel war es, eine Webanwendung von der Idee über die Modellierung bis zur prototypischen Umsetzung zu entwickeln.

## Inhalte
- Konzeption einer Website
- Erstellung von Diagrammen zur Struktur und Funktionsweise
- Implementierung eines Prototyps

## Technologien
- HTML & CSS – Frontend
- Python – Backend
- SQL – Datenbank

## Status
Die Anwendung ist ein **Prototyp**:
- Teilweise implementierte Funktionen
- Viele Dummy-Daten
- Fokus auf Lernprozess und Methoden

## Kontext
Studiengang: Wirtschaftsinformatik  
Semester: 2
